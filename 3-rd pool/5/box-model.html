Box Model на практике

Width и Height (размер блока)

Меняем ширину и высоту — блоки физически разного размера.

100×50

small

200×100

medium

300×150

large

Padding (внутренний отступ)

Padding — расстояние от края блока до текста ВНУТРИ него. Текст «отодвигается» от рамки.

padding: 10px

Маленький padding

padding: 40px

Большой padding

Margin (внешний отступ)

Margin — расстояние СНАРУЖИ блока, между ним и соседями. У красных блоков ниже разный margin — видно расстояние между ними.

margin: 5px
margin: 5px
margin: 30px
margin: 30px

Border (рамка)

Border — рамка вокруг блока. Можно менять толщину, цвет, стиль и скругление углов.

Тонкая чёрная рамка (1px solid)
Толстая пунктирная (5px dashed)
Скруглённая рамка (border-radius: 20px)

Всё вместе

Так выглядит структура: контент → padding → border → margin.
