# Блок 3. Массивы

Перебор, поиск, фильтрация, преобразование и сортировка массивов с выводом в вёрстку.

## Что встретилось

- Перебор массива: `forEach`, `for...of`.
- `filter` — фильтрация по названию и по флагу `completed`.
- `find` — поиск элемента по `id`.
- `map` — преобразование массива (цены со скидкой, строки-подписи).
- `sort` с компаратором и копирование через spread `[...arr]`, чтобы не менять исходный массив.
- Поиск максимума циклом (самый дорогой товар).
- Подсчёт суммы и количества циклом.
- Очистка контейнера перед перерисовкой.
- Поиск без учёта регистра через `toLowerCase()` + `includes()`.
- Сообщение «ничего не найдено» при пустом результате.
- Переключение представлений кнопками и `data-*` атрибуты.

## Задачи

| Папка | Задача | Метод |
|-------|--------|-------|
| task-1 | Каталог товаров | `forEach`, очистка контейнера |
| task-2 | Фильтрация по названию | `filter`, `includes`, регистр |
| task-3 | Поиск по id | `find` |
| task-4 | Преобразование цен | `map`, неизменность исходного массива |
| task-5 | Список задач | `filter`, переключение кнопками |
| task-6 | Корзина | сумма / количество / максимум в функциях |
| task-7 | Сортировка | `sort` + копия массива |
