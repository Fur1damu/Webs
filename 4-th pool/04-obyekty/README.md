# Блок 4. Объекты

Работа со свойствами объектов, вложенностью, деструктуризацией и шаблонными строками.

## Что встретилось

- Объявление объектов и обращение к свойствам через точку (`user.name`).
- Вложенные объекты (`product.specs.cpu`).
- Массив объектов и его перебор для генерации карточек.
- Условное оформление по свойству (`active` → класс и текст бейджа).
- Деструктуризация: `const { name, email, role } = user`.
- Шаблонные строки `` `...${value}...` `` вместо склейки через `+`.
- Массив внутри объекта (`order.items`) и динамическое построение таблицы.
- Подсчёт суммы из вложенного массива.
- Вставка готового HTML в контейнер через `innerHTML`.

## Задачи

| Папка | Задача | Что показывает |
|-------|--------|----------------|
| task-1 | Объект пользователя | Карточка профиля из свойств объекта |
| task-2 | Вложенный объект товара | Доступ к `specs`, список характеристик |
| task-3 | Массив объектов | Карточки пользователей, отметка активных |
| task-4 | Деструктуризация | Извлечение свойств, старый способ в комментарии |
| task-5 | Шаблонные строки | Карточка товара через template literals |
| task-6 | Объект заказа | Вложенный объект + массив + таблица + сумма |
