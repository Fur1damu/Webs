# Блок 1. Основы: переменные и условия

Базовые задачи на работу с вводом из вёрстки, переменные, условия и вывод результата на страницу.

## Что встретилось

- Поиск элементов через `document.querySelector`.
- Чтение значения поля через `input.value` и очистка пробелов через `.trim()`.
- Сохранение значений в переменные (`const`, `let`).
- Приведение строки к числу через `Number()` и проверка через `Number.isNaN()`.
- Условия: `if / else if / else`, цепочки условий, операторы сравнения (`<`, `<=`, `===`).
- Шаблонные строки: `` `Привет, ${name}!` ``.
- Вывод на страницу через `textContent`.
- Управление внешним видом через классы (`className`, `classList.add/remove`) — без inline-стилей.
- boolean-переменная и переключение состояния (`isOn = !isOn`).
- Обработчик клика `addEventListener('click', ...)`.

## Задачи

| Папка | Задача | Что делает |
|-------|--------|------------|
| task-1 | Кнопка приветствия | Читает имя и выводит «Привет, Имя!», либо «Введите имя» |
| task-2 | Калькулятор скидки | Считает цену со скидкой, проверяет корректность чисел |
| task-3 | Проверка возраста | Категории доступа по возрасту с проверкой пустого/отрицательного |
| task-4 | Форма регистрации | Проверка имени, email и пароля через JS (не через `required`) |
| task-5 | Проверка цены товара | Цепочка условий: бесплатно / дешёвый / обычный / дорогой |
| task-6 | Переключатель состояния | Включено/Выключено через boolean и класс |

## Как открыть

Открыть `index.html` нужной задачи в браузере (двойной клик).
