# Блок 5. Работа с данными

Подготовка и преобразование данных перед отрисовкой: `map`, `filter`, `reduce`, чистые функции.

## Что встретилось

- `map` для подготовки данных под UI (новые поля: `priceText`, `caption` и т.п.).
- Spread `{ ...product, ... }` для создания нового объекта без изменения исходного.
- `filter` по категории, по флагам (`active`, `role`).
- `reduce` для подсчёта количества и суммы из массива товаров заказа.
- `[...new Set(...)]` для получения уникальных категорий.
- Чистые функции: принимают аргументы, возвращают новый результат, не мутируют вход.
- Разделение логики фильтрации и сортировки на отдельные функции.
- Обновление UI по событиям `input` и `change`.
- Условные классы и текст в зависимости от данных (наличие, статус).
- Обработка пустой категории, чтобы интерфейс не ломался.
