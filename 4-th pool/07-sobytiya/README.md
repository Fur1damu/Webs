# Блок 7. События

Обработка событий: клики, ввод, отправка формы, делегирование.

## Что встретилось

- `addEventListener` с событиями `click`, `input`, `change`, `submit`, `keydown`.
- Хранение состояния в переменной (счётчик) и обновление DOM.
- `event.preventDefault()` для отмены отправки формы.
- Валидация полей формы в обработчике `submit`.
- Делегирование событий: один обработчик на контейнер.
- `event.target` и `closest()` для определения, по чему кликнули.
- `data-*` атрибуты для связи DOM-элемента с данными (`dataset.id`).
- Перерисовка списка после изменений (события работают и для новых элементов).
- Массив-состояние корзины: добавление, увеличение количества, удаление через `splice`.
- Подсчёт суммы через `reduce`.
