# Блок 6. DOM

Поиск, изменение, создание и удаление элементов страницы.

## Что встретилось

- `querySelector` для поиска элементов.
- `textContent` для смены текста.
- `classList.toggle / add / remove` — управление состоянием через классы (стили в CSS, без inline).
- `createElement` + `append` / `appendChild` для создания элементов.
- Проверка пустого ввода перед добавлением.
- `element.remove()` для удаления конкретного элемента.
- Свой обработчик удаления для каждого элемента.
- Полная генерация каталога из массива и очистка контейнера, чтобы карточки не дублировались.
- Показ/скрытие модального окна через класс (`is-open`), overlay.
- `event.target === overlay` для закрытия по клику на фон, закрытие по `Escape`.
- Динамическое построение строк таблицы и очистка `tbody`.
