# Блок 2. Функции и циклы

Вынесение логики в функции, использование `return`, циклы и генерация вёрстки на их основе.

## Что встретилось

- Объявление функций и `return` (`add`, `getSum`, `checkPassword`, `buildMenu` и т.д.).
- Разделение логики: отдельные функции операций + общая функция-диспетчер (`switch`).
- Циклы `for` и `for...of`.
- Генерация DOM-элементов в цикле (`createElement`, `append`).
- Очистка контейнера перед перерисовкой (`innerHTML = ''`).
- Функция, возвращающая объект-результат (`{ ok, reason }`).
- Регулярные выражения для проверки пароля (`/[0-9]/`, `/[a-zA-Zа-яА-Я]/`).
- Функция, возвращающая готовую HTML-строку, и вставка через `innerHTML`.
- Обработка деления на ноль.
- Разница между глобальной и локальной областью видимости, `ReferenceError`.

## Задачи

| Папка | Задача | Что делает |
|-------|--------|------------|
| task-1 | Калькулятор | Операции в отдельных функциях, диспетчер, деление на ноль |
| task-2 | Таблица умножения | Цикл 1–10, генерация строки в функции, очистка вывода |
| task-3 | Генератор карточек | Цикл по массиву, функция создания карточки |
| task-4 | Список чисел | Сумма и среднее в функциях, пустой ввод не добавляется |
| task-5 | Проверка пароля | Функция-валидатор, причина слабости или успех |
| task-6 | Генератор меню | Функция принимает массив и возвращает HTML |
| task-7 | Область видимости | Учебный пример global vs local |
