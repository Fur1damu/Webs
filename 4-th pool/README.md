# Практические задачи по JavaScript

Учебные задачи на чистом JS, завязанные на вёрстку: формы, карточки, каталоги, таблицы, шапки, списки, корзины.

Каждая задача — самостоятельная папка с тремя файлами: `index.html`, `style.css`, `script.js`.
Чтобы запустить одну задачу — откройте её `index.html` в браузере.

## 🖥️ Витрина (Windows 12)

В корне репозитория лежит `index.html` — рабочий стол в стиле Windows 12. Откройте его (или ссылку GitHub Pages), нажмите на экран блокировки — откроется **Проводник**, в котором можно ходить по блокам как по папкам и открывать любую работу в окне (через iframe). Удобно для проверки.

**Развёртывание (GitHub Pages):** Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)`.
Адрес будет: `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПО/`

> Важно: для витрины `index.html` **и все папки блоков** должны быть на одной ветке, которую публикует Pages (обычно `main`). Если блоки разнести по разным веткам, Проводник не сможет открыть работы.

## Git-процесс

Правила: **один блок — одна ветка**, **одна задача — один коммит**.

Пример для первого блока (остальные по аналогии):

```bash
git init                       # один раз для всего репозитория
git checkout -b 01-osnovy      # ветка под блок

git add 01-osnovy/task-1
git commit -m "Задача 1: кнопка приветствия с выводом имени из input"

git add 01-osnovy/task-2
git commit -m "Задача 2: мини-калькулятор скидки с проверкой чисел"
# ...по одному коммиту на задачу

git checkout main
git checkout -b 02-funkcii-i-cikly   # следующий блок — новая ветка
```

Готовые сообщения коммитов для каждой задачи лежат в `README.md` соответствующего блока.

## Технические заметки

- Только нативный JavaScript, без библиотек и сборки.
- Текст интерфейса и комментарии — на русском, имена переменных и функций — на английском.
- Состояния оформлены классами в CSS, инлайн-стили из JS не используются.
- Значения берутся из полей ввода, а не зашиваются в код.
